## PROFILE-3 · The donor profile, finished: one grid, three columns that scroll on their own, and a profile that looks good empty (2026-11-01)

Jonathan on a new donor in his test org (1 Nov): "The name and the tabs are not lined up. The right rail needs to scroll on its own and the big left window on its own. It's fine if it's empty if nothing has been logged, it just needs to look better." Measured on main: the back link and the header sat at 28px from the sidebar, the tabs at 27px and the timeline at 28px plus its own padding, so nothing shared an edge; the actions floated on the back link's row above the name. **The grid:** one 40px gutter for the main column (`--dp-gutter`), the face (72px) spanning the name, tags and contact rows, the actions centred on the name's row; Note, Email, Task and Atlas say their word when the header is wide and show their icon when it is not (a container query), so a two-word name fits on one line at 1440. **The columns:** PROFILE-2 made the profile one page because the old fixed panel scrolled nowhere; Jonathan now wants HubSpot's record page, so above 768 the frame is the window's height under its own top (measured, so a banner above it never hides the last item), the page never scrolls, and the main column and the rail are each a focusable scroll box; the header band, numbers and tabs are pinned in the main column. At 390 it is one page again. Every other page keeps PROFILE-2's rule. **Empty:** the numbers are an em dash with nothing under it (the no-emoji guard now lets a literal that is only the dash through; a dash beside words still fails), tab counts show above zero only, a person with nothing logged gets "Start Harold's story" with Log a call, Add a note and Record a gift, and the rail draws no empty section: Household and related, Contact, Groups, Engagement ("Nothing logged yet"), This fiscal year's inbox nudge, the cultivation plan and the default automatic-email card wait for something to say, and About carries Add email or phone, Link someone and the group picker meanwhile. "Unassigned" with a "?" face is an Assign link. Every rail section is now one white card under a brass small-caps label: the rail's text colours became CSS variables, so the same section code reads cream on the green and ink inside its card. **Tags:** a person with no gift got "New" (donorStatus's lifecycle) and "Donor" (the person type); the profile now drops every giving tag and the Donor word when there is no gift, until NUMBERS-4's tag rule says so on the server. **The split:** `DonorProfile.jsx` went from 4,112 lines to 1,488 (off the big-files baseline): verbatim moves of its dialogs and helpers, and its render's big blocks as components that take the locals they read (`components/profile/`, the largest `GivingTab.jsx` at 760). `readSource` reads every part, so the source-reading suites see the same code. Found and left: `OpenPledgeBanner`'s Record a payment sets the tab to "gifts", which is no longer a tab name.
