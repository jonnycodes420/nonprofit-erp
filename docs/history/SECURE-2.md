## SECURE-2 · Close what SECURE-1 left, and bring back the lost security list (2026-10-29)

SECURE-1 named nine holes it did not reach, and the 20 Oct security plan (two-factor, idle timeout, new-device alerts, export logging, a breach plan, restore steps, an honest security page) had been lost when its name was reused. This build did both lists, each fix with a section of `tests/security.test.js` (§11 to §18) run red first. Logs and Sentry: one redactor (`redact.js`) wraps console and is Sentry's beforeSend/beforeBreadcrumb; the browser's Sentry uses `client/src/lib/redactEvent.js`; every request has an X-Request-Id on its error line. Sign-up (`/public/signup`) answers 202 with one sentence whether or not the address has an account, the checkout link goes by email, and both answers wait for a 900 ms floor; forgot-password answers before it sends. The Mailchimp webhook secret is compared with timingSafeEqual. A campaign says "Sent to 412 of 500 · 88 not sent" with reasons, or "Not sent", from one function (`campaignDelivery.js`) that the campaign list, the sent list, Communications and the as-sent page read, and the truth check gained `mailCampaigns`. Inputs: `shared/contactCheck.js` (real syntax, a "did you mean") and `phoneNormal.js` (libphonenumber) on sign-up, invites, donor forms and the contact door Tell Steward uses; an import keeps a bad address and the profile and preview say "Check this email"; `middleware/fieldCaps.js` caps every text field by name on every write; `/donors` and `/donors/summaries` always page (100, at most 500) and the two whole-list screens page through (`client/src/lib/pages.js`); on a 25,000-person org no list route in the inventory answers more than 500 rows (`/donors/ids` stays the 25,000-id select-all by design). xlsx is SheetJS 0.20.3 from cdn.sheetjs.com and zod is past its advisory; real-shaped matched to the cent before and after. An enforced script CSP lives once in vercel.json (local-preview reads it); the smoke walk fails on any violation, and found an inline font handler on 186 prerendered pages. Two-factor (built in SEC-1) gained: turning it off takes an admin and emails the person. Idle sign-out per org (15 to 480 minutes, "Still there?", typing restored) and a new-device email (`user_devices`, fingerprint only; the first ever sign-in sends none). Every file download writes an audit row with its row count (Settings, Audit log, Exports), and a staff export of more than 1,000 people needs an admin or the org's setting. Papers in `docs/security/`: breach plan, restore steps, DPA draft, cookie plan (SECURE-3 if Jonathan says yes). Left: the legacy `/auth/register` and `/auth/register-org` still answer 409 for a taken address (only tests and the provisioning script call them); new-device mail names no place (no IP lookup without a new service).
