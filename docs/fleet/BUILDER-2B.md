# BUILDER-2B · For the fleet

**Surfaces changed:** every email editor (Communications → Templates → any designed template; a campaign's editor; a
journey step's email): the Elements tab (new tiles Columns, Box, Social, and Code for admins), the Blocks tab (saved
blocks and ready-made sections), the selected block's handles (a ⠿ grip), the drop line, the floating "+" between
blocks and its list, the Edit tab for Columns, Box, Social and Code, and "Save as a block" under a selected block's
settings. Communications → Templates → Brand: new "Social links".

**Clicks to try for the next three nights:**

   text puts the cursor there. Then click a part, and click the bottom right corner of the part ABOVE it: the part
