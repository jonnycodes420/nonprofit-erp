# Agent — two directions (FIX-1 §A, for Jonathan to pick)

Both are static mockups carrying the real Sunrise plan, inside the four colours
(ink ground, brass for what the agent is doing, emerald only for the one yes).
Rendered at 1440 and 390; neither scrolls sideways.

- **Direction 1 — The quiet room** (`direction-1-*.png`). One centred column read
  like a letter: the five views as an underline row, the plan as a numbered
  sequence with each step's state on the right, and a brass-edged card at the
  foot where the money waits for a person. Calm, one thing at a time.
- **Direction 2 — The run sheet** (`direction-2-*.png`). An ink desk with a cream
  sheet on it: every instruction she has given down the left with its run's
  state, the open plan on the right as a checklist (what it read, each step,
  its state), the confirm at the foot of the sheet. Busier, and it shows history
  and the current plan at once.
