## Gaps worth knowing before building

- Server delete routes with no client control: event levels, membership levels (and retire), opportunities archive, groups.
- No route at all: waiting-list removal, auction winner unassign, fund retire, p2p delete, tracked-sequence delete, survey delete, org-wide tag delete.
- Hard deletes that skip attached-row checks: giving / volunteer page (cascades P2P and volunteer sign-ups), groups, legacy sequences, logged hours, survey questions, campaigns with gifts.
- Pictures that are URL text boxes: giving page legacy modal, all three peer-fundraiser forms.
