# LANDING-2 photo manifest

All candidates are free Unsplash photos, usable commercially with no attribution required. Unsplash+ photos (paid, watermarked) are excluded.

**How to use this list**

1. Match each photo slot in the reference to a theme by its caption.
2. Download the photo from `https://unsplash.com/photos/<ID>/download?force=true`, resize it to WebP at 2x the slot size, and store it under the marketing images folder.
3. Open every image and check it actually matches its caption: warm, real, people smiling, nothing staged-looking or watermarked.
4. If an ID is dead or doesn't match, run the fallback search and pick a free photo instead.
5. Never use the same photo twice on one page.
6. Log every photo used, as slot → Unsplash URL, in `docs/landing/photo-credits.md`.
7. The four people in the reel and on Leadership (Jonathan, Winfield, Ross, Brad) reuse the portraits already live on the current landing page. Never use stock photos for them. That includes the Contact page photo captioned "Jonathan at a café": use his real portrait there.
