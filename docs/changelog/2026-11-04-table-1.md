title: A cleaner Donors table that stays tidy when you move or resize columns
product: crm
---
Every column on the Donors list now has its own width and alignment, so amounts, owners and scores never run into each other, and headings stay on one line. Resizing stops before a column gets too narrow, and when your columns no longer fit the table scrolls sideways with the donor's name kept in view. The widths and order you choose are saved for you, and Reset columns in Edit columns brings back the default.
