title: Safer edits: one person per Save, and a question before changes are lost
product: crm
---
Clicking Save twice now adds one person, and if the email is already on someone, Steward asks whether to open them or add a new person anyway. Leaving an edit with unsaved changes, by Back or the menu, now asks first. Households can lose one member without being deleted, tags can be removed in bulk with Undo or from a profile with one click, and deleting a person says when an open pledge goes with them.
