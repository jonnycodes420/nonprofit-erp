date: 2026-11-06
title: Undoing a large import always says what it removed
product: crm
---
When you undo a large import, Steward now shows how many gifts and people it removed as soon as it finishes. Before, there was a brief moment when it could say only that the import was removed. Steward also no longer starts the same journey twice for someone when two checks for a failed monthly gift happen at the same moment.
