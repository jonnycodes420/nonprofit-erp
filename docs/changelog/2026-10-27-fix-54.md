title: Someone you delete stays deleted
product: crm
---
When you select everyone matching a filter on the Donors page, Delete is now there too, and it deletes exactly the number it shows you. If a file you import names someone you deleted, Steward does not add them back: the preview names them, their rows are set aside, and they return only if you press Bring them back. Undoing an import never brings back anyone you deleted yourself.
