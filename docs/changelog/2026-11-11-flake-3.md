date: 2026-11-11
title: A page you leave mid-load no longer leaves work running behind it
product: platform
---
If you open a page and leave it, or refresh, before it has finished loading, Steward now stops the work that page had asked for, even when it had only just started. Before, a refresh at the wrong moment could leave a slow search running on the server for up to a minute, slowing things down for everyone. Leaving the Donors list while it loads also no longer counts as an error.
