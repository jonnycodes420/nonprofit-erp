Every change to Steward now runs your ten most important everyday tasks from start to finish before it can go live, from importing a file to thanking a gift to merging two records. After each release Steward also asks one real question and builds one real Agent plan on the demo organisation, saving nothing, and every night it runs twenty more against the real model, so a problem with Ask or the Agent is found by us before you see it.
