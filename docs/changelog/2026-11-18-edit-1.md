date: 2026-11-18
title: Open a task from a person's record to edit it
product: crm
---
Click a task's title anywhere on a person's record (Coming up, Activity or the Tasks tab) and it opens the same task window as the Tasks page. Change the day, the owner or the checklist, or add notes, and the record shows it at once. A task you have already ticked opens too, so you can write down what you did, or reopen it.
