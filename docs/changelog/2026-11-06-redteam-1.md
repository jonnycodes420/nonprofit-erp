title: Safer files and links, checked the way an attacker would
product: security
---
We tested Steward the way an attacker would, and closed what we found. Every spreadsheet Steward gives you now treats a cell that starts with =, +, - or @ as plain text, so a name or a survey answer can never run as a formula when you open the file. A file link on a donor's record must be a web address, and every page now answers another organization's records with "not found", the same as a record that doesn't exist.
