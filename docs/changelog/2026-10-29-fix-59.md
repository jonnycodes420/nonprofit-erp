date: 2026-10-29
title: Event imports that count each guest once, and Grow starts with second gifts
product: crm
---
When an event file has a guest list and a seating chart, Steward now asks whether two spellings of a name are the same person, keeps notes like "1 gluten free" off the guest list, and reads couples written with "or". Each event page counts declined guests on their own, so registered, came and didn't come add up, and imported attendance counts as checked in. Home's Grow tab now lists the first-time donors ready for a second gift first, and Data health re-checks your records after every import.
