date: 2026-10-18
title: Setup takes a gift file on its own, and checks your old report
product: crm
---
A single file with one gift per row and the donor's name on each row now imports through Set up Steward for me, the same way the Import screen brings it in, so you no longer need a separate people file. If your files include an old report, such as last year's giving summary, setup keeps it under Reports, checks it against what was imported, and puts the answer in one line on "Steward is ready" with a link to the full check.
