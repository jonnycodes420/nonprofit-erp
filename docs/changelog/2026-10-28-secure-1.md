title: A security review, and what it closed
product: security
---
We went through Steward the way an attacker would and closed what we found. Logos and pictures you upload are now always stored as ordinary images, a donor's name can never turn into code in an email preview, and exporting all of your organization's data or deleting a gift someone else entered now takes an admin. Sign-in links and cancel links expire, and the pages Steward serves now tell browsers to refuse the common tricks used against web apps.
