product: crm

Each connection now shows Connected only when Steward holds its sign-in and a check in the last day passed. Anything else says Needs attention, with the reason in a few words. Steward checks every connection once a day and keeps what each check found, and the panel shows the last three. When a connection goes quiet and nobody will be emailed about it, Home and the task now say so and point to the switch.
