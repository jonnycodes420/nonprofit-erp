title: Undo any import from its receipt, and imports that never time out
product: crm
---
Every import receipt now has an Undo button for 30 days, even when the file did not add up, and it tells you exactly what it will remove before it does anything. Importing a large file now runs in the background with a progress bar, so a slow connection or a closed tab never leaves you guessing: you always see either the receipt or the reason nothing was imported. Receipts count unpaid gifts as pledges, a notes sheet in a workbook is no longer read as more people, and someone you delete no longer shows up in event counts, totals or exports.
